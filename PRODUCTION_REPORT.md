## 1. Хураангуй

1. **Функцийн хувьд бэлэн.** Нийтийн сайт, нэвтрэлт (Clerk: Google + и-мэйл код), элсэлт,
   гишүүний хэсэг (/me), админ panel бүгд preview дээр ажилласан. Runtime-д mock өгөгдөл байхгүй.
2. **Production-д гаргахад хүлээгдэж буй зүйл:** өөрийн домэйн (Clerk production instance-д
   хэрэгтэй) → Clerk production тохиргоо → secret → D1 backup → migration 0006–0008 → deploy →
   анхны админ. Дараалал нь DEPLOY_CHECKLIST §7f-д байна.
3. **Аюулгүй байдал:** өмнөх тайлангийн P1 асуудлууд (login rate limit, security header, лог дахь
   хүүхдийн нэр) бүгд хаагдсан (§4).
4. **Гүйцэтгэл:** нийтийн хуудсанд Clerk огт ачаалагдахгүй болсон. Lighthouse devtools 99,
   simulated 92–96 (§6).
5. **Шударга дүгнэлт:** _"Тийм — домэйн ирэхэд."_ Кодын талаас хаалттай P1 алга. Үлдсэн нь
   тохиргоо, контент.

## 7. Production-д хийх ёстой зүйлс

Бүрэн жагсаалт, командууд: **DEPLOY_CHECKLIST.md §7f** (домэйн → Clerk production → var/secret
→ backup → migration → deploy → `admin:grant` → smoke test).

- Production D1-д migration 0000–0005 хийгдсэн; **0006 → 0007 → 0008 хүлээгдэж байна** (0007 нь
  хуучин нэвтрэлтийн хүснэгтүүдийг устгана — заавал backup-ын дараа).
- Local тест бүртгэлүүд (`+clerk_test`) зөвхөн Clerk **Development** instance болон local D1-д
  байгаа. Production instance хоосноос эхэлнэ.
